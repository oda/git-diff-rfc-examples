word-diff-align RFC examples

Supplemental four-way diff examples for the Git RFC patch series diff: pair edited lines inside moved blocks.

Each page compares git diff --histogram, --word-diff=plain, --color-moved=blocks, and the prototype --word-diff-align output.

The real-world page includes examples from CPython and Git covering opcode/constant renumbering, repeated row rewrites, table-width spacing changes, and shell-test refactoring.
